# Techne Base — Working Definition

Status: initial document, awaiting substantive definition.

## 1. Purpose

This document is the working location for developing the definition of **Techne Base**. Its nature, purpose, constituent concepts and relationships will be established progressively through the ensuing discussion. No substantive definition is assumed at this starting point.

## 2. Source context and separation

The existing [Abstography working definition](<../Episteme/01-ABSTOGRAPHY-WORKING-DEFINITION.md>) is source context only. It is not to be edited as part of this work.

Relevant concepts from that account may inform the definition here, but their applicability and relationship to Techne Base must be explained rather than assumed. The location of this document under `Poiesis Logic` does not, by itself, establish a conceptual relationship that has not yet been defined.

## 3. Development discipline

Develop this account step by step, distinguishing established definitions, provisional proposals and unresolved questions. When a definition changes, revise its dependent explanations so the document remains coherent as a whole. Preserve useful material in its proper context rather than accumulating contradictory versions.
